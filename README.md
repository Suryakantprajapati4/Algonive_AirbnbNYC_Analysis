# 🏠 Airbnb NYC — Data Analysis & Price Prediction

**Algonive Internship | Data Analytics | Task 2**

---

## 📌 Objective
Analyze Airbnb NYC listings to understand key pricing factors and build a 
machine learning model to predict listing prices based on features like 
location, room type, availability, and reviews.

---

## 📂 Dataset
- **Source:** [Kaggle — Airbnb NYC Open Data](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)
- **File:** AB_NYC_2019.csv
- **Size:** ~48,000 listings

---

## 🛠️ Technologies Used
- Python 3.9
- Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- Scikit-learn, XGBoost

---

## 📊 Project Pipeline
1. ✅ Data Cleaning & Preprocessing
2. ✅ Exploratory Data Analysis (EDA)
3. ✅ Feature Engineering
4. ✅ ML Model — Price Prediction
5. ✅ Dashboard & Visualization

---

## 🤖 Models Used
| Model | Result |
|---|---|
| Linear Regression | Baseline |
| Ridge Regression | Improved |
| Lasso Regression | Feature Selection |
| Decision Tree | Non-linear |
| Random Forest | ⭐ Best |
| Gradient Boosting | Close 2nd |
| XGBoost | Strong |

---

## 🔑 Key Findings
- Manhattan has the highest average listing price
- Entire home/apt listings are most expensive
- Location (borough & neighbourhood) is the strongest price predictor
- Random Forest gave the best R² score
